Portfolio professionnel présentant mes compétences en développement full-stack, intelligence artificielle et machine learning.

## 🚀 Aperçu

Ce portfolio est un site web statique moderne conçu pour présenter mon parcours professionnel, mes projets et mes certifications dans le domaine du développement logiciel et de l'IA.

## ✨ Fonctionnalités

- **Design Dark Theme** : Interface moderne avec thème sombre et effets animés
- **Animations Fluides** : Transitions et interactions utilisateur soignées
- **Responsive Design** : Optimisé pour tous les appareils (desktop, tablette, mobile)
- **Sections Complètes** :
  - Hero section avec animation de frappe
  - À propos avec principes professionnels
  - Expérience professionnelle avec timeline
  - Projets avec cards interactifs
  - Certifications avec carousel
  - Compétences techniques (Arsenal Technique)
  - Statistiques de coding (LeetCode, HackerRank)
  - Formulaire de contact (Formspree)

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Styles et animations
- **JavaScript (ES6+)** : Interactivité et animations
- **Font Awesome** : Icônes
- **Devicon** : Icônes de technologies
- **Formspree** : Gestion du formulaire de contact

## 🚀 Installation et Utilisation

### Cloner le dépôt
```bash
git clone https://github.com/bouthaynakhammasi/portfolio.git
cd portfolio
```

### Lancer localement
```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js (si installé)
npx serve
```

Ouvrez `http://localhost:8000` dans votre navigateur.

## 📝 Personnalisation

### Modifier les informations personnelles
- **Email** : Modifiez dans la section contact
- **LinkedIn** : Mettez à jour les liens LinkedIn
- **Projets** : Ajoutez/modifiez vos projets
- **Certifications** : Ajoutez vos certificats

### Modifier les statistiques de coding
Dans `script.js`, modifiez la fonction `setStaticStats()` :
```javascript
const stats = {
    leetcode: VOTRE_NOMBRE,
    hackerrank: VOTRE_NOMBRE
};
```

### Formulaire de contact
1. Créez un compte sur [Formspree](https://formspree.io/)
2. Remplacez l'endpoint dans le formulaire HTML
3. L'endpoint actuel est pour démonstration
